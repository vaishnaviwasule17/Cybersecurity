# Cybersecurity Threat Growth Analysis

The line graph illustrates the growth of major cybersecurity threats between 2023 and 2025.

#Insights
- DDoS attacks experienced the highest increase over the analyzed period.
- Phishing attacks remained one of the most prevalent threats.
- Malware incidents showed steady growth year over year.
- Ransomware attacks increased significantly, highlighting the need for stronger security controls.

This trend analysis demonstrates the evolving threat landscape and emphasizes the importance of proactive cybersecurity measures.

# Correlation Heatmap Analysis

The correlation heatmap was used to identify relationships between website characteristics and phishing behavior.

# Insights
- URL Length showed a strong positive correlation with phishing websites.
- Special Characters were highly associated with malicious URLs.
- HTTPS Usage showed a negative correlation with phishing activity, indicating that legitimate websites were more likely to use secure protocols.
- Strong correlations help identify the most useful features for machine learning-based phishing detection.

The heatmap provides valuable insights into feature relationships and supports effective feature selection for cybersecurity analytics.
